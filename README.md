How to run Transcription App?

SignUp/Login at ElevenLabs app and create a 
key at developers page

https://elevenlabs.io/app/developers/api-keys

Turn on Speech to Text option below while creating 
a key

Create .env file in main folder
Paste your key in .env file

ELEVENLABS_API_KEY = Paste here

Install required libraries using this command 
in IDE terminal.

pip install -r requirements.txt

Run "python main.py"
